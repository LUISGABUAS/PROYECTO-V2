Sistema de Gestión
Pacas Yadira

Implementación paso a paso para el equipo de Bodega, Ventas y Dirección

Esta presentación explica cómo funciona el sistema, qué hace cada módulo,
quién lo usa y cómo vamos a adoptarlo en el día a día de la empresa.

Visión general

¿Qué es el Sistema?

Es una plataforma web diseñada a medida para Pacas Yadira.
Reemplaza el control manual en hojas de cálculo y notas físicas por un sistema centralizado,
accesible desde cualquier dispositivo con internet.

🏭

Control de Bodega

Cada paca tiene un código único. Se sabe exactamente cuántas están en bodega, cuántas están vendidas y cuántas tienen dueño.

💰

Gestión de Ventas

Registro de ventas locales y foráneas con seguimiento de entregas, comprobantes y estado de cada pedido.

📊

Reportes en Tiempo Real

Dashboard con ventas del día, stock disponible, pacas pendientes de entregar y tendencias de los últimos 7 días.

¿Por qué lo necesitamos?

Los problemas que
teníamos antes

❌

Sin trazabilidad de pacas

No había forma de saber si una paca específica había sido vendida o estaba en bodega sin buscarla físicamente.

❌

Entregas sin control

Se podía entregar la misma paca dos veces, o no saber qué pacas le faltaban a una venta.

❌

Sin historial de ventas

Imposible saber cuánto vendió un vendedor, qué clientes compraron más, o cuál fue el mes más fuerte.

❌

Errores en pedidos foráneos

Los pedidos con envío mezclaban productos, costos de flete y cantidades sin un flujo claro.

La solución

Lo que el sistema resuelve hoy

✅

Código único por paca

Cada paca tiene un código de barras. Se escanea al salir y el sistema la marca como entregada automáticamente.

✅

Salida de bodega por escáner

El bodeguero escanea cada código al entregar. El sistema bloquea errores: pacas ya vendidas, pacas de otro cliente o pacas especiales.

✅

Pacas especiales separadas

Las pacas VIDEO y FLEJADA tienen su propio flujo. No se mezclan con ventas normales y se venden por separado con precio libre.

✅

Dashboard administrativo

Los jefes ven ventas totales, dinero generado, stock disponible y rendimiento por vendedor en tiempo real.

🏠 Venta Local

El cliente viene a recoger. El bodeguero selecciona la venta en pantalla y escanea cada paca al momento de entregar. El sistema cierra la venta automáticamente cuando están todas.

🚛 Venta Foránea

Se registra el envío con costo de flete. Se genera hoja de empaque con todos los productos. Se sube la guía de rastreo. El bodeguero escanea antes de embarcar.

Módulo: Almacén

Catálogo de Productos

El almacén es el catálogo maestro de todos los tipos de pacas que maneja la empresa.

📋 Información de cada producto

  • Nombre del producto
  • Código interno único
  • Categoría (ropa, calzado, etc.)
  • Precio de venta sugerido
  • Imagen del producto
  • Faltantes / reposición

📦 Información de stock en tiempo real

  • Pacas disponibles en bodega
  • Pacas con venta pendiente de entrega
  • Pacas disponibles netas
  • Historial de movimientos
  • Importar stock masivo por CSV
  • Etiquetas de bodega imprimibles

Cuando el stock de un producto llega a cero, aparece automáticamente en la lista de faltantes para gestionar reposición con proveedores.

Módulo: Stock

Inventario Paca a Paca

Cada paca física tiene un código único en el sistema. Este código es la identidad de la paca durante toda su vida en la empresa.

🏷️

Código único

Se genera al registrar la paca. Se imprime como etiqueta y se pega físicamente en la paca.

🔄

Estados de la paca

EN BODEGA → disponible.
VENDIDO → entregada.
ESPECIAL → VIDEO o FLEJADA.

📥

Importación masiva

Se puede cargar un archivo CSV con cientos de pacas a la vez. El sistema asigna códigos automáticamente.

Si un bodeguero escanea una paca que ya fue vendida, el sistema lo bloquea y le pregunta si quiere devolverla al inventario (como FLEJADA o como normal).

Módulo: Ventas

Registro y Gestión de Ventas

📝 Al crear una venta

  • Seleccionar cliente (local o foráneo)
  • Elegir productos y cantidades
  • Agregar costo de envío si aplica
  • Elegir tipo de pago (efectivo, comprobante, ambos)
  • El sistema calcula el total automáticamente

📋 Tipos de venta

  • Venta local (cliente recoge)
  • Venta foránea (con envío)
  • Pedido múltiple (varios envíos)
  • Cotización (sin confirmar aún)
  • Paca especial VIDEO / FLEJADA
🧾

Comprobantes

Se adjuntan fotos de transferencias o recibos directamente a la venta.

📄

Hoja de empaque

Documento imprimible con todos los productos de la venta para bodega.

✏️

Edición flexible

Se puede editar la venta si aún no está completamente entregada.

Módulo: Salida de Bodega

Escaneo de Entregas

Este módulo es el corazón del trabajo diario de bodega.
El bodeguero selecciona la venta y escanea cada paca al entregarla.

1

Seleccionar período y tipo de venta

Filtrar por fecha y elegir si es venta local o foránea. El sistema muestra la lista de ventas pendientes de entregar.

2

Seleccionar la venta del cliente

Se hace clic en el nombre del cliente o se busca. Aparece el detalle de qué pacas se deben entregar.

3

Escanear cada paca

Con pistola de código de barras o cámara. El sistema emite un sonido de confirmación y actualiza el contador en tiempo real.

4

Venta completada automáticamente

Cuando todas las pacas de la venta han sido escaneadas, el sistema la cierra y actualiza el estado al instante.

Módulo: Pacas Especiales

Pacas VIDEO y FLEJADA

🎥

Paca VIDEO

Paca que se revisó en video para el cliente. Se vende por separado a un precio negociado. No sale en el flujo normal de bodega.

🎀

Paca FLEJADA

Paca devuelta, abierta o rebolsada. Se reagrupa y se vende con precio especial. También puede volver a entrar al inventario normal.

A

Marcar paca como especial

Desde el módulo de Stock, el encargado selecciona la paca y la marca como VIDEO o FLEJADA con una nota opcional.

B

Vender desde Pacas Especiales

En el menú "Pacas Especiales" se eligen, se selecciona el cliente, se pone el precio libre y se confirma. El sistema genera la venta independiente.

Si alguien escanea una paca FLEJADA o VIDEO en la salida normal, el sistema la bloquea y avisa que debe venderse desde el módulo especial.

Módulo: Clientes

Base de Datos de Clientes

🏠 Clientes Locales

  • Nombre completo
  • Teléfono de contacto
  • Vendedor asignado
  • Historial de compras
  • Ventas pendientes de entrega

🚛 Clientes Foráneos

  • Nombre y datos de contacto
  • Ciudad y estado de destino
  • Paquetería preferida
  • Historial de envíos con guías
  • Pedidos con múltiples destinos

Cada vendedor ve solo sus clientes. El administrador ve todos. Los clientes no se pueden duplicar: el sistema advierte si ya existe un cliente con el mismo teléfono.

Seguridad

Controles de seguridad del sistema

🔒

Sin doble venta

El sistema usa bloqueo de base de datos (SELECT FOR UPDATE) para evitar que dos vendedores vendan la misma paca al mismo tiempo.

🛡️

Permisos por módulo

Cada página verifica el permiso antes de cargar. Sin el permiso correcto, el acceso es denegado y se muestra alerta.

📋

Auditoría completa

Cada acción importante queda registrada: quién creó la venta, quién escaneó la paca, qué se modificó y cuándo.

🔄

Protección ante errores

Si el bodeguero escanea una paca vendida, bloqueada o especial, el sistema avisa con sonido y mensaje en lugar de registrar un error silencioso.

El sistema corre en servidor en la nube (pacasyadira.com). Los datos están respaldados. Accesible desde cualquier celular, tablet o computadora.

Plan de capacitación y arranque

6 fases para arrancar sin caos

El sistema no se activa de golpe. Se adopta por fases para que cada área aprenda a su ritmo y nadie se sienta perdido.

🔧

Fase 1 — Preparar

El admin configura el sistema solo antes de involucrar al equipo. Usuarios, catálogo y prueba interna.

👔

Fase 2 — Dirección

Los jefes aprenden primero. Deben entender el sistema antes de explicárselo a otros.

💼

Fase 3 — Vendedores

Sesión práctica: crear venta, adjuntar comprobante, ver sus pendientes.

📦

Fase 4 — Bodega

Sesión práctica: imprimir etiquetas, escanear salidas, identificar pacas especiales.

⚖️

Fase 5 — En paralelo

Una semana usando sistema Y método anterior. Se comparan resultados al final del día.

🚀

Fase 6 — Solo el sistema

Cuando 5 días seguidos sin diferencias, se abandona el método manual para siempre.

Fase 1 · Solo el admin · 1 día

Preparar antes de tocar con el equipo

Antes de capacitar a nadie, el administrador deja todo listo. El equipo no toca el sistema hasta que esto esté completo.

1

Crear todos los usuarios y asignar roles

Una cuenta por persona: nombre, contraseña temporal (ej. paca2026) y rol correcto. Admin, Supervisor, Vendedor, Bodeguero. ~1 hora.

2

Capturar el catálogo de productos en Almacén

Dar de alta cada tipo de paca: nombre, código, categoría, precio. Sin este paso los vendedores no pueden hacer ventas. Si hay lista en Excel, se puede importar. ~2-3 horas.

3

Hacer una prueba interna completa

Entrar con usuario de vendedor de prueba → crear venta ficticia. Entrar con usuario de bodega → escanear esa venta. Confirmar que cada rol ve solo lo que debe ver.

Fase 2 · Días 1-2 · 1 hora

Capacitar a Dirección primero

Los jefes aprenden antes que el equipo operativo. Deben saber leer el sistema para poder resolver dudas y detectar errores.

📊

Dashboard — leer las métricas

Cómo ver ventas totales del período, monto generado, stock disponible y comparativa local vs foráneo. Cómo cambiar el rango de fechas.

👥

Ver ventas de todos los vendedores

Cómo filtrar por vendedor, ver el detalle de cada venta y cuáles están pendientes de entrega en toda la empresa.

🔍

Auditoría — quién hizo qué

Cómo revisar el registro de acciones: quién creó cada venta, quién escaneó cada paca y qué se modificó.

🔑

Gestión de usuarios

Cómo crear, editar o bloquear usuarios. Qué hacer si alguien olvida su contraseña o si entra personal nuevo.

Regla de dirección: revisar el dashboard cada mañana antes de iniciar operaciones y auditoría una vez al mes.

Fase 3 · Día 3 · 1 hora por grupo

Capacitar al equipo de Ventas

Se capacita por grupo pequeño o de uno en uno. No mezclar con bodega: cada área aprende solo lo suyo.

A

Entrar al sistema desde celular o computadora

Abrir pacasyadira.com en el navegador. Iniciar sesión con su usuario. Cambiar la contraseña temporal.

B

Crear un cliente y registrar una venta

Ir a Clientes → Crear. Luego Ventas → Nueva Venta: elegir cliente, productos, cantidades y tipo de pago. El sistema calcula el total.

C

Adjuntar comprobante de pago

Desde la venta, subir foto del comprobante o transferencia al momento de recibirlo. No dejarlo para después.

D

Ver sus ventas pendientes

En Ventas → Mis ventas, ver qué pedidos están pendientes de entrega y cuáles están completos.

Regla clave: "La venta se registra el mismo día que se cierra, no después."

Fase 4 · Día 4 · 1 hora

Capacitar al equipo de Bodega

Bodega aprende en su propio módulo. No necesita saber de ventas ni clientes. Solo su flujo.

A

Imprimir etiquetas y pegarlas en pacas físicas

Desde Stock → Etiquetas de bodega, imprimir los códigos de barras de cada paca y pegarlos físicamente. Esto se hace una sola vez al registrar inventario nuevo.

B

Usar la Salida de Bodega paso a paso

Filtrar por fecha → elegir Local o Foráneo → seleccionar la venta del cliente → escanear cada paca. Escuchar los sonidos: bip OK = bien, error = parar y reportar.

C

Identificar pacas FLEJADA y VIDEO

Estas pacas tienen etiqueta especial. No van al escaneo normal. Si el sistema las bloquea, avisar al supervisor. Se venden por el módulo "Pacas Especiales".

Regla de oro: "Nunca entregues una paca sin escanearla. Si el sistema dice error, para y avisa — no fuerces."

Fase 5 · Días 5-12 · Semana de transición

Arranque en paralelo — la semana más importante

Primera semana: el equipo usa el sistema y además lleva el control anterior como respaldo. Esto permite detectar errores sin riesgo.

📋

Cómo funciona el paralelo

Vendedores registran ventas en el sistema y en su cuaderno o Excel de siempre. Bodega escanea en el sistema y anota en su hoja de control. Al final del día se comparan los dos registros.

🔎

Quién revisa cada día

El supervisor o jefe saca el reporte del día desde el Dashboard y lo compara con el control manual. Si hay diferencia, se investiga antes del día siguiente.

✅

¿Cuándo se abandona el método manual?

Cuando 5 días seguidos el sistema y el manual coinciden sin diferencias. Normalmente sucede entre el día 7 y el día 10.

⚠️

Si hay diferencia un día

No pasa nada — para eso existe el paralelo. Se identifica el error, se corrige en el sistema y se vuelve a contar. El contador de "días sin diferencias" reinicia.

Fase 6 · Semana 3 en adelante

Operación normal — solo el sistema

📅 Rutinas de operación

  • Cada mañana: admin revisa dashboard
  • Cada venta: se registra el mismo día
  • Cada entrega: se escanea paca por paca
  • Cada entrada de mercancía: se registra y etiqueta
  • Cada semana: revisar pacas pendientes globales
  • Cada mes: auditoría de usuarios y permisos

🗓️ Resumen de tiempos del arranque

  • Día 1 — Admin prepara: usuarios, catálogo, prueba
  • Día 2 — Capacitación a Dirección (1 hora)
  • Día 3 — Capacitación a Vendedores (1 hora)
  • Día 4 — Capacitación a Bodega + etiquetar
  • Días 5-12 — Operación en paralelo
  • Semana 3 — Solo el sistema, método anterior: adiós

La clave del éxito no es el sistema — es la disciplina del equipo. Un solo dato que no se capture rompe el inventario. Todos capturan todo, siempre.

Operación diaria

Reglas de uso para cada área

💼

Equipo de Ventas

✓ Registrar cada venta el mismo día que se cierra.
✓ Adjuntar comprobante de pago al momento.
✓ No tomar pedido de una paca que el sistema marque sin stock.
✓ Usar cotización si el cliente no confirma aún.

📦

Equipo de Bodega

✓ Escanear cada paca antes de entregarla. Nunca saltarse el escaneo.
✓ Si el sistema bloquea una paca, reportar de inmediato (no forzar).
✓ Las pacas FLEJADA y VIDEO no van al flujo normal de entrega.

👔

Dirección / Admin

✓ Revisar el dashboard cada mañana antes de iniciar operaciones.
✓ Verificar pacas pendientes globales cada semana.
✓ Auditoría mensual de usuarios y permisos activos.
✓ No compartir contraseñas entre usuarios.

La calidad del sistema depende del 100% de captura. Una venta no registrada o una paca no escaneada rompe el inventario. El sistema solo funciona bien si todos lo usan.

FAQ

Preguntas frecuentes del equipo

¿Qué pasa si no tengo internet?

El sistema requiere conexión. En bodega se recomienda tener una red WiFi estable. Si hay corte, las operaciones se registran en papel y se capturan al volver la señal.

¿Desde qué dispositivos se usa?

Desde cualquier navegador: celular, tablet o computadora. No se instala nada. Solo se abre pacasyadira.com en el navegador.

¿Qué pasa si escaneo la paca equivocada?

El sistema avisa si la paca no pertenece a esa venta. Si ya se registró por error, el administrador puede devolver la paca al inventario desde el módulo de Stock.

¿Puedo hacer una devolución?

Sí. Al escanear una paca que ya fue vendida, el sistema pregunta si quieres devolverla y te da la opción de regresarla como paca normal o como FLEJADA.

¿Los datos están seguros?

Sí. El sistema corre en un servidor en la nube con respaldos. Solo personas con usuario y contraseña pueden acceder.

¿Puedo ver las ventas de otro vendedor?

No, a menos que tengas permiso de supervisor o administrador. Cada vendedor solo ve sus propias ventas y clientes.
